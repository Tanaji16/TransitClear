# TransitClear 🚛

**Transport & Logistics Road Safety Portal** — A web platform that helps drivers report road problems, receive real-time alerts, and plan safer journeys.

## Features

### For Drivers
- 🔐 Secure signup/login (Email + Google)
- 🏠 Dashboard with route overview
- ⚠️ Real-time road alerts
- 📍 Report road problems (potholes, floods, accidents)
- 🗺️ Journey planning with safety warnings
- 👤 Driver profile management

### For Authorities (Coming Soon)
- 📊 Admin dashboard with analytics
- 🛣️ Road problem management
- 📢 Alert broadcasting
- 👥 User management
- 🔒 Access restrictions management

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript (Vanilla)
- **Backend:** Firebase (Auth, Firestore, Hosting)
- **Design:** TailwindCSS + Custom CSS
